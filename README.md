# Web Sistem Digital Jimpitan & Kas Dusun Kiyudan

Sistem Informasi Digital Pengelolaan Jimpitan Mingguan, Tabungan Warga, Kas Pemuda, dan Kas Dusun Kiyudan, Desa Majaksingi, Kecamatan Borobudur, Kabupaten Magelang.

## 🌟 Fitur Utama
- **Transparansi Keuangan Publik Terbuka**: Laporan mingguan, bulanan, tahunan, rentang periode kustom (misal Agustus 2026 s/d Mei 2027), dan rekapitulasi 40 KK warga.
- **Cek Tabungan Mandiri Warga**: Pencarian data warga & cetak/unduh buku tabungan pribadi berformat PDF resmi.
- **Input Pengambilan Jimpitan**: Pembagian otomatis 50% Kas Pemuda & 50% Kas Dusun, validasi duplikasi tanggal unik, rekonsiliasi uang fisik & selisih, serta fitur koreksi data yang sudah diposting dengan audit log lengkap.
- **Master Data Warga & Kelompok**: Pengelolaan 40 KK warga aktif dan 4 kelompok jimpitan bergilir.
- **Pusat Laporan & Ekspor PDF**: Dokumen PDF resmi berstandar Kop Surat Dusun Kiyudan (3 baris resmi, logo dusun, garis ganda, dan tanda tangan Ketua Pemuda Humam Syarif & Bendahara).

## 🚀 Menjalankan Aplikasi Secara Lokal
Aplikasi ini berbasis Vanilla JavaScript, HTML5, dan CSS3 murni tanpa dependensi rumit.

1. Jalankan server lokal:
```bash
node server.js
```
2. Buka browser pada alamat:
```
http://localhost:8080/
```
